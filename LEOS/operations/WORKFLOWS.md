# LEOS Supported Workflows

The Workflow Orchestrator automatically detects the requested workflow based on the user prompt and routes it through the standard pipeline.

## 1. Software Review

- **Trigger:** "Review [Product]"
- **Focus:** Commercial investigation, Platinum depth.
- **Outputs:** Full pipeline execution resulting in a heavily structured, feature-rich MDX file.

## 2. Comparison

- **Trigger:** "[Product A] vs [Product B]"
- **Focus:** Buying decision matrix, balanced recommendation.
- **Outputs:** MDX featuring side-by-side spec tables, winner declarations, and pros/cons.

## 3. Tutorial

- **Trigger:** "How to [Action]"
- **Focus:** Informational intent, step-by-step clarity, security callouts.
- **Outputs:** MDX optimized for `HowTo` schema and snippet extraction.

## 4. Pillar

- **Trigger:** "Best [Category]"
- **Focus:** Topical authority, maximum internal linking.
- **Outputs:** Massive (5000+ words) hub article acting as the cluster center.

## 5. Pricing Guide

- **Trigger:** "[Product] Pricing"
- **Focus:** Commercial intent, decision support, hidden cost exposure.
- **Outputs:** MDX featuring master pricing tables and ROI analysis.

## Future/Planned Workflows

- **Alternatives Guide:** (e.g., "[Product] Alternatives")
- **Roundup:** (e.g., "Top 10 [Category]")
- **Refresh Existing Article:** Automated audits to update `LastUpdated` metadata and verify deprecated facts.
- **Cluster Creation:** End-to-end generation of an entire topical cluster.
