## 3. Link Hygiene & Anchor Text Guidelines

1. **No Exact-Match Overuse**: Vary anchor text naturally (e.g., alternate between "AI mock interview software", "practicing interview questions with AI", and "AI interview prep tools").
2. **Relative Linking Only**: All internal link hrefs MUST use relative paths without protocol or domain (`/blog/[slug]`).
3. **Contextual Placement**: Injected link anchors must occur naturally within introductory paragraphs or tactical recommendation blocks, avoiding forced "click here" lists.
