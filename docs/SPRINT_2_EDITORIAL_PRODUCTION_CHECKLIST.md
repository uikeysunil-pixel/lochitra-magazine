## 2. 12-Point Pre-Writing Verification Checklist

### 1. Keyword Intelligence Verified

- [ ] Primary keyword volume and difficulty scores validated against 2026 search benchmarks.
- [ ] Secondary keywords (3–5 semantic variations) identified and mapped.
- [ ] Primary target keyword confirmed in single-quotes inside frontmatter specs.

### 2. Live SERP Analysis Reviewed

- [ ] Top 5 organic ranking URLs inspected for structure, length, and content depth.
- [ ] Google AI Overview presence verified and summary format noted.
- [ ] People Also Ask (PAA) questions extracted for inclusion in FAQ section.
- [ ] Reddit, forum, and video pack presence evaluated.

### 3. Search Intent Confirmed

- [ ] Primary search intent classified (Commercial Investigation, Informational, Tactical Financial, Career Transition).
- [ ] Target audience persona defined (Job Seeker, Mid-Career Upskiller, Remote Worker, Tech Leader).
- [ ] Commercial Intent Score assigned (0 to 10 scale).

### 4. Competitor Analysis Complete

- [ ] Primary competitors identified (HBR, Forbes, Coursera, BuiltIn, Levels.fyi, Deel).
- [ ] Weaknesses and thin coverage areas in competitor articles documented.
- [ ] Locitra proprietary framework / unique differentiation angle specified.

### 5. Internal Link Mesh Planned

- [ ] Minimum 3–5 existing Locitra articles identified for internal linking.
- [ ] Relative slug URLs (`/blog/[slug]`) mapped with natural, non-exact-match anchor text.
- [ ] Target page reciprocal links identified (Zero-Orphan Policy compliance).

### 6. Authoritative External Sources Identified

- [ ] Minimum 3 primary sources selected (Official documentation, peer-reviewed research, WEF/OECD workforce studies, SEC filings).
- [ ] No low-quality secondary blog citations permitted.

### 7. Affiliate & Monetization Opportunities Identified

- [ ] Primary SaaS or EdTech affiliate partners selected (Coursera, Final Round AI, Deel, Levels.fyi, Taplio).
- [ ] AdSense RPM target tier confirmed ($50–$85 range).
- [ ] Lead magnet resource selected for `<BlogNewsletterForm />` callout.

### 8. Structured Data Schema Selected

- [ ] Primary Schema selected (`Article`).
- [ ] Secondary Schema selected (`FAQPage`, `HowTo`, or `ItemList` as appropriate).

### 9. Featured Image Brief Prepared

- [ ] Image prompt formulated for 1200x630 WebP asset generation.
- [ ] Asset path designated: `/static/images/blog/[slug].webp`.
- [ ] Image brief checked against visual standard (NO stock photo look, NO text, NO logos).

### 10. E-E-A-T Trust Signals & Disclosures Documented

- [ ] Mandatory `<AffiliateDisclosure />` component placement confirmed immediately after frontmatter.
- [ ] Hands-on evaluation methodology notes documented.
- [ ] Disclaimers prepared (financial, legal, tax where applicable).

### 11. LEOS System Compliance Confirmed

- [ ] `frontmatterVersion: '2.0'` included in specification.
- [ ] Prohibited constructs verified: 0 HTML comments (`<!-- -->`), 0 JSX comments (`{/* */}`), 0 body H1s (`#`), 0 inline markdown images.
- [ ] Heading hierarchy confirmed as Title Case H2s and H3s.

### 12. Gold Standard v2.1 Validation Complete

- [ ] Article brief aligned with existing articles in `career-growth` category.
- [ ] Paragraph rhythm capped at 3–4 sentences maximum.
- [ ] Markdown comparison tables and formatted bullet lists specified.
