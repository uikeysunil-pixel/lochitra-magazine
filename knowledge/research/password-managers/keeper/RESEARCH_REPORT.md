# RESEARCH REPORT: Keeper Security (2026)

## 1. Product Overview

- **Name:** Keeper Security (Keeper Password Manager)
- **Category:** Password Manager
- **Primary Market:** Enterprise, Business, Privacy-conscious consumers.
- **Core Value Proposition:** Zero-knowledge, zero-trust security architecture with deep compliance certifications.

## 2. Security Architecture

- **Encryption:** AES-256-bit encryption with PBKDF2 for key derivation.
- **Model:** Zero-Knowledge architecture. Keeper employees cannot access user vaults.
- **Compliance:** SOC 2 Type 2, ISO 27001, HIPAA, FedRAMP Authorized.
- **Audits:** Regular third-party penetration testing (NCC Group, Cybertest).

## 3. Key Features

- KeeperFill (Auto-fill across all devices)
- BreachWatch (Dark web monitoring)
- KeeperChat (Encrypted messaging)
- Secure File Storage
- Passkey Management (Full passkey support across mobile and desktop)
- Advanced 2FA (YubiKey, Duo, Biometrics, Authenticator apps)
- Keeper Secrets Manager (For developers/DevOps)

## 4. Pricing (2026 Data)

- **Keeper Free:** Basic, single device.
- **Keeper Unlimited:** ~$35/year.
- **Keeper Family:** ~$75/year (up to 5 users, 10GB storage).
- **Business/Enterprise:** Custom pricing based on seats and add-ons.

## 5. Competitor Analysis

- **vs. 1Password:** Keeper is often seen as slightly more utilitarian/enterprise-focused, whereas 1Password has a more polished UI for consumers. Both offer exceptional security.
- **vs. Bitwarden:** Bitwarden is open-source and cheaper, but Keeper offers deeper enterprise compliance features like FedRAMP.

## 6. Target Audience

- **Ideal For:** IT professionals, businesses requiring compliance, families seeking robust security.
- **Not Ideal For:** Users looking for a feature-rich free tier (Bitwarden is better here) or the absolute sleekest UI (1Password).
